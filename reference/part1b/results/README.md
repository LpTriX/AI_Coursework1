- 环境：CPython 3.9.6，macOS / Darwin 27.0.0，arm64。
- 被测代码 commit：`a431cc1eddeea8f7a47bc8a792a31e1d3b8428a0`。
- 被测代码和输入没有未提交改动；各文件哈希在原始数据中。
- 每题重复 5 次，共 15 次；没有额外的预热运行。
- 计时包含初始化搜索结构和递归，不含输入读取/验证、打印以及解的独立验证。

同一输入的五次结果与搜索计数一致；用时有波动。所有返回的完整棋盘都通过行、列、宫和原始给定数字的独立集合检查。没有做唯一性证明。

自带的无解例子可以手工检查：第一行缺少数字 1，但第一列已经存在 1，所以第一格没有可填数字。它只覆盖立即发现矛盾的无解情况，不代表所有无解题都能如此快速结束。

这三个样例没有正式难度或来源认证，也没有运行其他搜索方法作对比。因此不能把表格解读成“该方法对任意题目都很快”或“优于某个未测试的方法”。正式作业应重新选择可追溯来源的题目，在自己编写的实现上测量并自行分析。
