# Python 数独学习参考


依赖：Python 3.10 或更新版本，只使用标准库，不使用任何 Sudoku、CSP 或约束求解器库。

## 当前实现阶段

输入层已支持 TXT、CSV、UTF-8 BOM、行列数量、数字范围以及给定数字的行/列/宫冲突检查。单元测试使用标准库 unittest。

在仓库根目录运行：

```sh
python3 -m unittest reference.part1b.test_solver -v
```

## 输入

- 9 行，每行 9 个单数字；0 表示空格。
- TXT 使用空白分隔，CSV 使用逗号分隔。
- 文件末尾允许正常换行；额外空白行、少行、多行、非整数、越界数字和初始冲突会被拒绝。

## 练习数据

`standard.txt` 与 `branching.txt` 是本次会话转录的练习输入，没有经过外部来源、唯一性或正式难度认证。名称只是标识，不能直接当成报告中的难度分级或数据来源。

`unsatisfiable.txt` 是从规则生成的完整棋盘改造的反例：初始给定数字无直接重复，但不存在完整解。程序必须通过搜索/候选值检查判定无解，不能将其误归类为格式错误。

正式实验应使用你自行收集、可追溯来源的多个题目，并保存真实测量。
